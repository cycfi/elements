Sizing

Overview

Size elements override the limits of an enclosed element. There is a comprehensive list of size related elements in the Elements Library that can be used for various purposes. This section catalogues all the available size elements.

Each returns a Proxy. Except for vcollapsible and hcollapsible, which collapse an axis to zero, the natural limits of the element will not be violated.

vcollapsible

Collapses the height of an enclosed element (subject).

A collapsible element folds its enclosed element (subject) away on one axis when a predicate says so, and brings it back when the predicate changes its mind: the subject’s limits on that axis are both set to zero, so the tile or grid it sits in gives it no room and what follows moves up, or over, to take its place; it is not drawn, and takes neither the mouse nor the keyboard. The subject is still there, and returns at its own size as soon as the predicate is false again. A section of a panel that folds under its header, or a sidebar that slides out of the way, is built this way.

The predicate is read when the enclosing element lays out. After changing what it returns, call the view’s layout() so the tree is laid out again.

Declaration

template <concepts::Element Subject>
class vcollapsible_element : public proxy<Subject>
{
public:
   using is_collapsed_function = std::function<bool()>;

                           vcollapsible_element(Subject subject);

   is_collapsed_function   is_collapsed = []{ return false; };

   ...
};

template <concepts::Element Subject>
vcollapsible_element<remove_cvref_t<Subject>>
vcollapsible(Subject&& subject);

The rest of vcollapsible_element is the Proxy interface (see Proxies).

Expressions

Notation

subject

Instance of Element

pred

A callable returning bool, bool()

e

Factory

Expression Semantics

vcollapsible(subject)

While pred() returns true, the min and max height of the subject’s limits are zero; its width is untouched. The subject is not drawn, and wants_control and wants_focus return false. While pred() returns false, the subject’s limits are its own, and it is drawn and takes events as usual.

Mutators

Expression Semantics Return Type

is_collapsed is a public member holding pred; its default returns false.

Example

A row of three boxes, 10 apart: one of a fixed size, one at least 100 wide, and one at most 60 wide:

#include <elements/element/size.hpp>
#include <elements/element/tile.hpp>        // For htile
#include <elements/element/style/misc.hpp>  // For box
...
using namespace cycfi::elements;
...
auto row = htile(
   fixed_size({40, 40}, box(colors::red)),     (1)
   hspace(10),                                 (2)
   hmin_size(100, box(colors::green)),         (3)
   hspace(10),
   hmax_size(60, box(colors::blue))            (4)
);
1 A box fixed at 40 by 40.
2 An empty space 10 wide.
3 A box at least 100 wide.
4 A box at most 60 wide.

A section of a panel: a header, a body on its own background that folds under it, and what follows:

#include <elements/element/size.hpp>
#include <elements/element/align.hpp>        // For align_left
#include <elements/element/label.hpp>        // For label
#include <elements/element/layer.hpp>        // For layer
#include <elements/element/margin.hpp>       // For margin, margin_top
#include <elements/element/style/misc.hpp>   // For rbox
#include <elements/element/tile.hpp>         // For vtile
...
using namespace cycfi::elements;
...
struct section
{
   bool open = true;

   auto make()
   {
      auto body = vcollapsible(
         layer(
            margin({10, 10, 10, 10}, align_left(label("Collapsible section"))),
            rbox(rgba(50, 70, 100, 255))
         ));
      body.is_collapsed = [this]{ return !open; };
      return vtile(
         align_left(label("A section").font_size(16)),
         margin_top(6, std::move(body)),
         margin_top(8, align_left(label("What follows the section")))
      );
   }
};

To fold it, set open to false and call view_.layout().
