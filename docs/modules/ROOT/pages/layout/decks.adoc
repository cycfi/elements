= Decks

include::../common.adoc[]

== Overview

The Deck is very similar to {Layers}. Elements are placed in the z-axis. But
unlike layers, only the selected element is active (top-most by default).

image::/layout/deck.svg[alt="deck", width=353px, role=center]

`deck` returns a `Composite`.

== Include

```c++
#include <elements/element/layer.hpp>
```

== deck

=== Layout Rules

. Everything listed in the {Layers_Layout_Rules}, except 2 and 3.
. Only the active selected element is drawn.
. Only the active selected element is given the chance to process UI control.

=== Declaration

```c++
class deck_element : public layer_element
{
public:

   void                    select(std::size_t index);
   std::size_t             selected() const;

   ...
};

using deck_composite = vector_composite<deck_element>;

template <concepts::Element... E>
array_composite<sizeof...(E), deck_element>
deck(E&&... elements);
```

`deck` returns an `array_composite` and `deck_composite` is a
`vector_composite`, each with `deck_element` as its base. The rest of
`deck_element` is the `Composite` interface (see
xref:elements/composites.adoc[Composites]).

=== Expressions

==== Notation

`N`:: The number of items

`+e1,...eN+`:: One or more child elements, instances of `Element`.

`c`:: Instance of type `deck_composite`

`d`:: A deck: the element `deck` returns, or a `deck_composite`

`index`:: `std::size_t`

==== Factory

[cols="1,1"]
|===
| Expression                    | Semantics

| `+deck(e1,...eN)+`
| Create a deck composite with a fixed number of elements. Elements
  `+e1,...eN+` are held in a `std::array<element_ptr, N>` managed by the
  deck element.
|===

.Example
[,c++]
----
deck(item1, item2, item3, item4)
----

NOTE: If the number of elements is not fixed, you can use a
`deck_composite` (see below).

==== Constructors

[cols="1,1"]
|===
| Expression                    | Semantics

| `deck_composite c`
| Create a deck with an indeterminate (dynamic) number of elements.
|===

The `deck_composite` is essentially a `std::vector<element_ptr>` that the
client uses to manage the composite's elements. The client is responsible for
the lifetime of the container, `c`. You use `deck_composite` just as you
would a `std::vector`, such as using `push_back` to add a child element.
Remember that the items are `element_ptr` instances. The first element of `c`
is selected by default.

.Example
[,c++]
----
c.push_back(share(child));
----

NOTE: `share` turns an element object into an `element_ptr` held by
the `std::vector<element_ptr>` in `deck_composite`.

`deck_composite` is itself also an `element` and while it has ``std::vector``'s
interface, it can also be ``share``d like any element, which allows you to
build complex hierarchical structures.

==== Mutators

[cols="1,1,1"]
|===
| Expression                    | Semantics                         | Return Type

| `d.select(index)`
| Select the element at `index`, counting from 0. An `index` past the last
  element is ignored. If the deck has the focus, the newly selected element
  takes it. The view is not refreshed: refresh the deck to draw
  the newly selected element.
| `void`
|===

==== Accessors

[cols="1,1,1"]
|===
| Expression                    | Semantics                         | Return Type

| `d.selected()`
| Get the index of the selected element; 0 by default.
| `std::size_t`
|===

== Example

Two pages, one shown at a time, and a button that flips between them:

```c++
#include <elements/element/layer.hpp>
#include <elements/element/indirect.hpp>      // For hold
#include <elements/element/size.hpp>          // For fixed_size
#include <elements/element/tile.hpp>          // For vtile
#include <elements/element/style/button.hpp>  // For button
#include <elements/element/style/misc.hpp>    // For box
#include <elements/view.hpp>                  // For view
...
using namespace cycfi::elements;
...
auto pages = share(deck(
   box(colors::gold),                                          <1>
   box(colors::slate_gray)
));

auto flip = button("Flip");
flip.on_click =
   [&view_, pages](bool)
   {
      pages->select(1 - pages->selected());                    <2>
      view_.refresh(*pages);                                   <3>
   };

auto content = vtile(
   fixed_size({200, 100}, hold(pages)),
   flip
);
```

<1> The first element, selected by default: the gold box is drawn.
<2> Select the other element: only it is drawn.
<3> `select` does not refresh the view: refresh the deck to draw the newly
selected element.
