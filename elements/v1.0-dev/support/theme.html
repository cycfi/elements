Theme

Overview

Elements draws its controls from one global theme: the colors, fonts, sizes and radii every label, button, slider and frame is drawn with. Change the theme and every control changes with it, without touching the controls themselves.

  • Left, the default theme.

  • Right, the same controls with label_font_color amber and indicator_color, with its two derived shades, green.

  • Nothing else differs: the controls are built the same way in both.

Most of the theme is read each time a control draws, so a change shows at the next redraw; call refresh on the view to have it redrawn at once. Some values are taken when a control is made instead, as the default of a constructor argument: the body color of buttons, icon buttons and menus, button_corner_radius, the fonts of text boxes and menu items, the pane opacity, the active tab color, and the sizes and OK color of dialogs and message boxes. A control made before a theme change keeps those. Set the theme before building the view, and it applies to everything.

Include

#include <elements.hpp>

Declaration

namespace cycfi::elements
{
   class theme
   {
   public:
                           theme();

      // The members, listed under Members below.
   };

   theme const&            get_theme();
   void                    set_theme(theme const& thm);

   template <typename T>
   class scoped_theme_override;

   template <typename T>
   scoped_theme_override<T>
                           override_theme(T theme::*pmem, T val);
}

Expressions

Notation

t

A theme.

pmem

A pointer to a theme member of type T, such as &theme::label_font_color.

val

A value of type T.

Semantics

Expression Semantics Return Type

theme{}

A theme with the default values, listed under Members.

theme

get_theme()

The global theme.

theme const&

set_theme(t)

Replace the global theme with t.

void

override_theme(pmem, val)

Set one member of the global theme to val until the returned object goes out of scope, then put back the value it had.

scoped_theme_override<T>

Example

Set a theme once, before the view is made, to style the whole application. The right-hand figure above was drawn after this:

theme t;
t.indicator_color = rgba(67, 160, 71, 230);
t.indicator_bright_color = t.indicator_color.level(1.5);
t.indicator_hilite_color = t.indicator_color.level(2.0);
t.label_font_color = rgba(255, 200, 80, 230);
set_theme(t);

To change one member for a while, override it and let the override go out of scope:

{
   auto larger = override_theme(&theme::frame_corner_radius, 12.0f);
   // Frames drawn here have 12 unit corners.
}
// Back to the previous radius.
