= Grids

include::../common.adoc[]

== Overview

Grids are similar to tiles. Both tiles and grids allow elements to fluidly
adjust depending on available space. Grids lay out its elements using
externally supplied normalized fractional coordinates that specify positions
of the elements in the allocated space.

Grids are best for composing tables.

Each factory returns a `Composite`.

== Include

```c++
#include <elements/element/grid.hpp>
```

== hgrid

image::/layout/hgrid.svg[alt="hgrid", width=347px, role=center]

Horizontal Grids are composites that lay out one or more child elements in a
row following externally supplied horizontal fractional positions. Horizontal
Grids have computed horizontal and vertical sizes following the natural
{limits} of its children.

image::/layout/hgrid_equal.svg[alt="hgrid_equal", width=347px, role=center]

Without supplied positions, a horizontal grid lays out its elements in
columns of equal width.

=== Layout Rules

. The elements are laid out in a single row, left to right, immediately next
to each other with no intervening space.
. The elements are positioned horizontally using the supplied fractional
positions. The fractional positions values range from 0.0 to 1.0, which
specify the child element's horizontal position from left (0.0) to right
(1.0).
. The grid's _minimum vertical limit_ is computed as the maximum of the
children elements' __minimum vertical limit__s.
. The grid's _maximum vertical limit_ is computed as the minimum of the
children elements' __maximum vertical limit__s.
. The final computed maximum limit is clamped to ensure it is not less
than the computed minimum limit: the minimum wins.
. The supplied (horizontal) positions and computed (vertical) coordinates
may violate the limits of its children elements.
 .. If the allocated size of a child element is lower than the element's
_minimum limits_ in either dimension, the element is given its cell, smaller
than its minimum, without clipping.
 .. If a child element's _maximum limits_ in either dimension is exceeded,
the element is given its full cell.

=== Declaration

```c++
class hgrid_element : public grid_base
{
   ...
};

using hgrid_composite = vector_composite<
   container_grid<std::vector<float>, hgrid_element>
>;

template <std::size_t N, concepts::Element... E>
array_composite<sizeof...(E), range_grid<hgrid_element>>
hgrid(float const(&coords)[N], E&&... elements);

template <std::size_t N, concepts::Element... E>
array_composite<sizeof...(E), array_grid<N, hgrid_element>>
hgrid(float const(&&coords)[N], E&&... elements);

template <std::size_t N, concepts::Element... E>
array_composite<sizeof...(E), array_grid<N, hgrid_element>>
hgrid(std::array<float, N> const& coords, E&&... elements);

template <concepts::Element... E>
array_composite<sizeof...(E), equal_grid<hgrid_element>>
hgrid(E&&... elements);
```

`hgrid` returns an `array_composite` and `hgrid_composite` is a
`vector_composite`, each with `hgrid_element` as its base, under a class that
supplies the positions: `range_grid` refers to a plain array, `array_grid`
holds a copy, `equal_grid` divides the grid equally, and `container_grid`
refers to a container. All of `hgrid_element` is the `Composite` interface (see
xref:elements/composites.adoc[Composites]).

=== Expressions

==== Notation

`N`:: The number of items

`+e1,...eN+`:: One or more child elements, instances of `Element` (more below)

`positions`:: External container of fractional positions (more below)

`c`:: Instance of type `hgrid_composite`

==== Factory

[cols="1,1"]
|===
| Expression                    | Semantics

| `+hgrid(positions, e1,...eN)+`
| Build a horizontal grid with a fixed number of elements. The external
  container, `positions`, can either be a plain array of type `float[N]` or
  `std::array<float, N>`. Elements `+e1,...eN+` are held in a
  `std::array<element_ptr, N>` managed by the horizontal grid element.
| `+hgrid(e1,...eN)+`
| Build a horizontal grid with a fixed number of elements in columns of
  equal width, one column per span.
|===

.Example
[,c++]
----
static float positions[] = {0.25, 0.5, 0.75, 1.0};
//...
hgrid(positions, item1, item2, item3, item4)
----

A named plain array of positions is not copied: it must outlive the grid, as
a `static` array does. A `std::array` or a braced list of positions, such as
`+hgrid({0.25f, 1.0f}, item1, item2)+`, is copied into the grid.

NOTE: If the number of elements is not fixed, you can use an
`hgrid_composite` (see below).

==== Requirements

. The number of supplied positions and elements, multiplied by each element's
span, should match, otherwise, undefined behavior.  By default elements have
a span of `1`. See xref:layout/span.adoc#_span_element[Span Element] for more
information.
. The positions assume the first element is at `x=0` (it is at the left-most
position in the row). The fractional position of the second element is at
index `0`, the third at index `1`, and so on.
. The externally supplied positions should be sorted with increasing values
such that positions[n] \<= positions[n+1]. The behavior is undefined if
this is violated.

==== Constructors

[cols="1,1"]
|===
| Expression                    | Semantics

| `+hgrid_composite c{positions}+`
| Create a horizontal grid with an indeterminate (dynamic) number of
  elements. `positions` is an external container of fractional positions,
  `std::vector<float>`.
|===

The `hgrid_composite` is essentially a `std::vector<element_ptr>` that the
client uses to manage the composite's elements. The client is responsible for
the lifetime of the container, `c`. You can use `hgrid_composite` in the same
way as a `std::vector`, such as using `push_back` to add a child element.
Remember that the items are `element_ptr` instances.

.Example
[,c++]
----
c.push_back(share(child));
----

NOTE: `share` turns an element object into an `element_ptr` held by
the `std::vector<element_ptr>` in `hgrid_composite`.

`hgrid_composite` is itself also an `element` and while it has ``std::vector``'s
interface, it can also be ``share``d like any element, which allows you to
build complex hierarchical structures.

==== Requirements

. The number of items in the external coordinates vector `positions` must match
with the number of elements, multiplied by each element's span, at any given
time.
. The positions assume the first element is at `x=0` (it is at the left-most
position in the row). The fractional position of the second element is at
index `0`, the third at index `1`, and so on.
. The externally supplied positions should be sorted with increasing values
such that positions[n] \<= positions[n+1]. The behavior is undefined if
this is violated.

== make_equal_grid

Makes the positions of `N` equal columns or rows, for a grid that takes
`positions`.

=== Declaration

```c++
template <std::size_t N>
std::array<float, N>
make_equal_grid();
```

=== Expressions

==== Notation

`N`:: The number of positions, a `std::size_t` constant

==== Functions

[cols="1,1,1"]
|===
| Expression                    | Semantics                         | Return Type

| `make_equal_grid<N>()`
| Get `N` equally spaced positions: `1/N`, `2/N`, ... `1.0`.
| `std::array<float, N>`
|===

The grid keeps a copy of the array, so it may be made in place:

[,c++]
----
hgrid(make_equal_grid<4>(), item1, item2, item3, item4)
----

== Example

A table of three rows of equal height: two rows on columns a quarter, a
quarter and a half of the width, and one row of two equal columns:

```c++
#include <elements/element/grid.hpp>
#include <elements/element/size.hpp>        // For span
#include <elements/element/style/misc.hpp>  // For box
...
using namespace cycfi::elements;
...
static float const columns[] = {0.25, 0.5, 1.0};               <1>

auto table = vgrid(                                             <2>
   hgrid(columns,
      box(colors::red),
      box(colors::green),
      box(colors::blue)
   ),
   hgrid(columns,
      box(colors::gold),
      span(2, box(colors::steel_blue))                          <3>
   ),
   hgrid(box(colors::slate_gray), box(colors::white))           <4>
);
```

<1> The ends of three columns: a quarter, a half, and the full width.
<2> Three rows of equal height.
<3> The steel blue box spans the second and third columns.
<4> Two columns of equal width.
