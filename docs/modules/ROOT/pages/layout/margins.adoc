= Margins

include::../common.adoc[]

== Overview

Margins add some space around elements. There is a comprehensive list of
margin elements in the Elements Library that can be used for various
purposes. This section catalogues all the available margin elements.

Each returns a `Proxy`. The element's {limits} is overridden to account for
the additional space. A margin element does not violate the natural {limits}
of the subject. It will respect the subject's min-max constraints and
resizability.

== Include

```c++
#include <elements/element/margin.hpp>
```

== margin

image::/layout/margin.svg[alt="margin", width=302px, role=center]

Adds a margin all around an enclosed element (`subject`).

=== Declaration

```c++
namespace concepts
{
   template <typename T>
   concept Rect = requires(T r)
   {
      { r.left } -> std::convertible_to<float>;       // left margin
      { r.right } -> std::convertible_to<float>;      // right margin
      { r.top } -> std::convertible_to<float>;        // top margin
      { r.bottom } -> std::convertible_to<float>;     // bottom margin
   };
}

template <concepts::Rect Rect, concepts::Element Subject>
class margin_element : public proxy<Subject>
{
public:
                           margin_element(Rect margin_, Subject subject);

   ...
};

struct static_empty_rect
{
   static constexpr int    left = 0;
   static constexpr int    right = 0;
   static constexpr int    top = 0;
   static constexpr int    bottom = 0;
};

template <concepts::Element Subject>
margin_element<rect, remove_cvref_t<Subject>>
margin(rect margin_, Subject&& subject);
```

`rect` is the {artist} rectangle. Every factory on this page returns a
`margin_element`. The other factories give it a struct derived from
`static_empty_rect`: the struct sets the sides the factory names, and the
other sides are zero. The rest of `margin_element` is the `Proxy` interface
(see xref:elements/proxies.adoc[Proxies]).

=== Expressions

==== Notation

`left`, `top`, `right`, `bottom`:: `float`

`subject`:: Instance of `Element`

==== Factory

[cols="1,1"]
|===
| Expression                    | Semantics

| `margin({left, top, right, bottom}, subject)`
| Space is added to the left, top, right, and bottom of the subject with
  the given parameters.
|===

== hmargin

(same as `margin_left_right`)

image::/layout/hmargin.svg[alt="hmargin", width=302px, role=center]

Adds a margin to the left and right sides of an enclosed element (`subject`).

=== Declaration

```c++
struct hmargin_rect : static_empty_rect
{
                           hmargin_rect(float left, float right);
                           hmargin_rect(float left_right);

   float                   left;
   float                   right;
};

template <concepts::Element Subject>
margin_element<hmargin_rect, remove_cvref_t<Subject>>
hmargin(hmargin_rect margin_, Subject&& subject);

template <concepts::Element Subject>
margin_element<hmargin_rect, remove_cvref_t<Subject>>
hmargin(float left, float right, Subject&& subject);

template <concepts::Element Subject>
margin_element<hmargin_rect, remove_cvref_t<Subject>>
margin_left_right(hmargin_rect margin_, Subject&& subject);

template <concepts::Element Subject>
margin_element<hmargin_rect, remove_cvref_t<Subject>>
margin_left_right(float left, float right, Subject&& subject);
```

=== Expressions

==== Notation

`left`, `right`:: `float`

`left_right`:: `float`

`subject`:: Instance of `Element`

==== Factory

[cols="1,1"]
|===
| Expression                    | Semantics

| `hmargin({left, right}, subject)`
| Space is added to the left and right sides of the subject with the
  given parameters.
| `hmargin(left, right, subject)`
| Same as `hmargin({left, right}, subject)`.
| `hmargin(left_right, subject)`
| Space is added to the left and right sides of the subject, `left_right`
  on each.
| `margin_left_right({left, right}, subject)`
| Same as `hmargin({left, right}, subject)`.
| `margin_left_right(left, right, subject)`
| Same as `hmargin({left, right}, subject)`.
| `margin_left_right(left_right, subject)`
| Same as `hmargin(left_right, subject)`.
|===

== Example

A row of three boxes: one with a margin of 10 all around, one with 20 on its
left and right, and one 30 down from the top:

```c++
#include <elements/element/margin.hpp>
#include <elements/element/tile.hpp>        // For htile
#include <elements/element/style/misc.hpp>  // For box
...
using namespace cycfi::elements;
...
auto row = htile(
   margin({10, 10, 10, 10}, box(colors::red)),      <1>
   hmargin({20, 20}, box(colors::green)),           <2>
   margin_top(30, box(colors::blue))                <3>
);
```

<1> A box with a margin of 10 on each side.
<2> A box with a margin of 20 on its left and right.
<3> A box with a margin of 30 on its top.
