= Icons

include::../common.adoc[]

== Overview

Elements draws its icons from a font, `elements_basic.ttf` in
`resources/fonts`, built with https://fontello.com[Fontello]. Each icon is
a glyph at a code point in the font's private use area, and
`support/icon_ids.hpp` names them: `icons::ok`, `icons::cancel`,
`icons::cog` and so on, 265 in all.

An icon code goes wherever an element takes one:

* `icon(code, size)`, an element that is just the icon, `size` a
  multiplier on the theme's icon size.
* `icon_button(code, size)` and `plain_icon_button(code, size)`, buttons
  whose face is an icon.
* `button(code, label)` and `button(label, code)`, a button with an icon
  before or after its label.
* `draw_icon` and `measure_icon`, for a custom styler. See
  xref:support/text_utils.adoc[Text Utilities].

The font and its size come from the theme: `icon_font` and
`icon_color`. See xref:support/theme.adoc[Theme].

== Declaration

```c++
namespace cycfi::elements::icons
{
   enum
   {
      left     = 0xe800,
      right    = 0xe801,
      up       = 0xe802,
      down     = 0xe803,
      // ... every name in the table, in the same order ...
      expand   = 0xe84f,
      shrink   = 0xe850,
      // ... and the icons added later, from 0xe851 ...
   };
}
```

The names are an anonymous enum, so a code converts to the
`std::uint32_t` the icon functions take. Most codes run from `0xe800`;
five early icons (`sliders`, `lightbulb`, `hand`, `menu`, `unlink`) came
from Font Awesome and keep its code points, and the many added since
from the same set take codes in sequence from `0xe851`. `mixer` is another name for
`sliders`: the same glyph.

== Adding Icons

The 265 icons are a starting set. An application adds its own by building
a new icon font with Fontello and shipping it in place of Elements':

. Go to https://fontello.com[fontello.com] and drop
  `resources/fonts/config.json` on the page. The 267 glyphs load with
  their names and codes, so everything Elements draws keeps working.
. Add your icons: pick from Fontello's font sets, or drag in your own
  SVG files.
. Give each new glyph a code point from `0xf800`: click the glyph,
  then its code.
+
WARNING: Codes below `0xf800` are reserved. `0xe800` to `0xefff` are
Elements' own icons, and `0xf000` to `0xf2ff` are glyphs Fontello imports
from other fonts, which keep their own codes. An application's icons go
in `0xf800` to `0xf8ff` (256 codes), so they never collide with icons
Elements adds later.
. Download the webfont. In the archive, `font/elements_basic.ttf` is the
  new font and `config.json` the new configuration; keep the latter with
  the font, so the next addition starts from it.
. Before including `ElementsConfigApp.cmake`, point the build at the
  new font:
+
```cmake
set(ELEMENTS_ICON_FONT ${CMAKE_CURRENT_LIST_DIR}/resources/my_icons.ttf)
```
+
The font keeps the family name `elements_basic`, which the theme's
`icon_font` names, so nothing else changes.
. Name your codes in an enum of your own:
+
```c++
namespace my_icons
{
   enum
   {
      waveform  = 0xf800,
      midi_plug = 0xf801
   };
}

auto b = icon_button(my_icons::waveform);
```

auto settings = icon_button(icons::cog);
