== Overview

The tutorials take you from an empty window to a control of your own,
in five programs. Each one is an example from `examples/`, so you can
build it, run it, and change it as you read. Each builds on the one
before, so read them in order the first time.

Before you start, build the library and its examples, as described in
xref:setup.adoc[Setup and Installation]. Every tutorial ends with the
command that builds its program.

[cols="1,3"]
|===

| xref:tutorials/hello_universe.adoc[Hello Universe]
| A window with a picture in it. The four parts of every program.

| xref:tutorials/layout.adoc[Laying Out a Window]
| How elements are arranged: fixed sizes, stretching, alignment,
  grids and flows.

| xref:tutorials/controls.adoc[Controls and Values]
| Sliders, knobs and buttons, and how your program reacts to them.

| xref:tutorials/model.adoc[The Model]
| Keeping a value in one place when several controls show it.

| xref:tutorials/custom_control.adoc[A Custom Control]
| An element of your own: drawing it and giving it the mouse.
|===

The reference pages, under xref:reference.adoc[Reference], describe
every element in full. Each tutorial links to the pages for what it
uses, and ends with a table of them.

== More Examples

After the tutorials, the other examples show one part of the library
each. Read the program alongside its reference page.

[cols="1,3"]
|===
| Example | Shows

| `empty`
| A blank window: a starting point for a program of your own.

| `buttons`
| Every kind of button, with icons, sprites and styles. See
  xref:styles/buttons.adoc[Button Styles].

| `sprite_sliders_and_knobs`
| Sliders and knobs drawn from images. See
  xref:elements/sliders.adoc[Sliders] and xref:elements/dials.adoc[Dials].

| `range_slider`
| A slider with two thumbs. See xref:elements/sliders.adoc[Sliders].

| `thumbwheels`
| Thumbwheels of every kind. See
  xref:elements/thumbwheels.adoc[Thumbwheels].

| `scale`
| The same controls drawn at different scales. See
  xref:layout/scale.adoc[Scale].

| `text_and_icons`
| Labels, text boxes, input boxes and icons. See
  xref:elements/text.adoc[Text] and xref:support/icons.adoc[Icons].

| `text_edit`
| A text editor. See xref:elements/text.adoc[Text].

| `icons_list`
| Every icon in the library. See xref:support/icons.adoc[Icons].

| `list`, `active_list`, `selection_list`, `table_list`, `list_arranger`
| Lists: long, editable, selectable, in columns, and rearranged by
  dragging. See xref:elements/lists.adoc[Lists].

| `sync_scrollbars`
| Two scrollers that move together. See
  xref:elements/ports.adoc[Ports and Scrollers].

| `notebook`
| Pages behind tabs. See xref:styles/notebooks.adoc[Notebooks].

| `menus`
| Menus, menu items and shortcuts. See xref:elements/menus.adoc[Menus].

| `popups`, `tooltip`
| Popups and tooltips. See xref:elements/popups.adoc[Popups] and
  xref:elements/tooltips.adoc[Tooltips].

| `dialogs`
| Dialogs and message boxes. See xref:styles/dialogs.adoc[Dialogs].

| `child_window`, `dock`, `split`
| Windows within the view, docked windows, and splits. See
  xref:elements/child_windows.adoc[Child Windows],
  xref:elements/docking.adoc[Docking] and xref:elements/splits.adoc[Splits].

| `status_bars`
| Progress bars, busy bars and meters. See
  xref:elements/status_bars.adoc[Status Bars].

| `drop_file`
| Files dropped on the window. See
  xref:elements/drag_and_drop.adoc[Drag and Drop].

| `rain`
| An animation, redrawn on a timer. See xref:view.adoc[View] and
  xref:support/canvas.adoc[Canvas].
|===
