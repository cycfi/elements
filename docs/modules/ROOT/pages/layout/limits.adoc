= Limits

include::../common.adoc[]

== Overview

Each element provides information on how it wants to be sized by means of
`min` and `max` limits: a hint that determine its actual extent and how it
will be placed in the view depending on available window space.

`view_limits` is a struct that gives us the `min` and `max` information.

By default, an element has full limits, meaning there is no constraints on
its size. It is infinitely resizable. An element with `full_limits` can be
resized from an empty point (zero x and y size) up to the full extent of the
screen, and beyond (if possible).

== Terms and Expressions

For the purpose of this document, we will use these terms and expressions:

limits:: The limits of an element

limits.min:: The minimum limits of an element

limits.min.x:: The minimum horizontal limit of an element

limits.min.y:: The minimum vertical limit of an element

limits.max:: The maximum limits of an element

limits.max.x:: The maximum horizontal limit of an element

limits.max.y:: The maximum vertical limit of an element

horizontal limits:: (limits.min.x, limits.max.x)

vertical limits:: (limits.min.y, limits.max.y)

minimum limits:: (limits.min.x, limits.min.y)

maximum limits:: (limits.max.x, limits.max.y)

minimum horizontal limit:: limits.min.x

maximum horizontal limit:: limits.max.x

minimum vertical limit:: limits.min.y

maximum vertical limit:: limits.max.y

== Include

```c++
#include <elements/base_view.hpp>
```

== Declaration

```c++
constexpr float         full_extent = /* implementation defined */;

struct view_limits
{
   point                min = {0.0, 0.0};
   point                max = {full_extent, full_extent};
};

constexpr view_limits   full_limits = {
                           {0.0, 0.0}
                         , {full_extent, full_extent}
                        };
```

== Expressions

=== Notation

`limits`, `a`, `b`:: Objects of type `view_limits`.

`mn`, `mx`:: Objects of type `point` for the minimum and maximum limits.

`full_extent`:: An implementation-defined huge number that signifies an
unbounded extent.

`point`:: A data structure representing a coordinate in a 2D space used to
specify positions or dimensions within the graphical context.

=== Constructors and Assignment

[cols="1,1"]
|===
| Expression                  | Semantics

| `view_limits{}`             | Construct a `view_limits` with full
                                limits, the same as `full_limits`.
| `view_limits{mn, mx}`       | Construct a `view_limits` given `mn`
                                (minimum limits) and `mx` (maximum
                                limits).
| `view_limits(limits)`       | Copy construct from `view_limits limits`.
| `a = b`                     | Assign `b` to `a`.
|===

NOTE: `view_limits` is an aggregate, so it is built with braces.

=== Access

[cols="1,1,1"]
|===
| Expression        | Semantics                               | Return Type

| `limits.min`      | Access the minimum limits of an
                      element.                                | `point`
| `limits.min.x`    | Access the minimum horizontal limit of
                      an element.                             | `float`
| `limits.min.y`    | Access the minimum vertical limit of an
                      element.                                | `float`
| `limits.max`      | Access the maximum limits of an
                      element.                                | `point`
| `limits.max.x`    | Access the maximum horizontal limit of
                      an element.                             | `float`
| `limits.max.y`    | Access the maximum vertical limit of an
                      element.                                | `float`
|===

* An element has a fixed horizontal size if this expression is true:
`limits.min.x == limits.max.x`.
* An element has a fixed vertical size if this expression is true:
`limits.min.y == limits.max.y`.

=== Constants

[cols="1,1,1"]
|===
| Expression        | Semantics                               | Return Type

| `full_extent`     | Get the unbounded extent.               | `float`
| `full_limits`     | Get the full limits, from an empty
                      point up to `full_extent` on both axes. | `view_limits`
|===

=== Example

Limits for a fixed size, for a fixed width with a flexible height, and for a
fixed width with a height from 100 to 200:

```c++
#include <elements/base_view.hpp>
...
using namespace cycfi::elements;
...
view_limits fixed = {{100, 100}, {100, 100}};            <1>
view_limits tall = {{100, 100}, {100, full_extent}};     <2>
view_limits semi = {{100, 100}, {100, 200}};             <3>
```

<1> Fixed size.
<2> Fixed width, flexible height.
<3> Fixed width, semi-flexible height (100 to 200).
