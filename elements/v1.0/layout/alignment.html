Alignment

Overview

An element can be aligned arbitrarily from 0.0 to 1.0 in either the x or y dimensions, or both. There is a comprehensive list of align elements in The Elements Library that can be used for various purposes. This section catalogues all the available align elements.

Each factory returns a Proxy.

Include

#include <elements/element/align.hpp>

halign, align_left, align_center and align_right

Aligns the enclosed element (subject) in the x-axis.

Left-aligns the enclosed element (subject).

Center-aligns the enclosed element (subject).

Right-aligns the enclosed element (subject).

Declaration

template <concepts::Element Subject>
class halign_element : public proxy<Subject, align_element_base>
{
public:
                           halign_element(float align, Subject subject);

   void                    align(float align);
   float                   align() const;

   ...
};

template <concepts::Element Subject>
halign_element<remove_cvref_t<Subject>>
halign(float align, Subject&& subject);

template <concepts::Element Subject>
halign_element<remove_cvref_t<Subject>>
align_left(Subject&& subject);

template <concepts::Element Subject>
halign_element<remove_cvref_t<Subject>>
align_center(Subject&& subject);

template <concepts::Element Subject>
halign_element<remove_cvref_t<Subject>>
align_right(Subject&& subject);

The align members come from align_element_base, which valign_element shares. The rest of halign_element is the Proxy interface (see Proxies).

Factory

Expression Semantics

halign(align, subject)

Given a total allocated space X, subject will be positioned horizontally to X * align. The subject takes the available space up to its maximum horizontal limit, and is positioned by align when that is less than the space. For its minimum, use halign(align, hmin(subject)).

align_left(subject)

Equivalent to halign(0.0, subject).

align_center(subject)

Equivalent to halign(0.5, subject).

align_right(subject)

Equivalent to halign(1.0, subject).

Example

A 40 by 40 box aligned three ways in a column, and three ways in a row:

#include <elements/element/align.hpp>
#include <elements/element/size.hpp>        // For fixed_size
#include <elements/element/tile.hpp>        // For vtile and htile
#include <elements/element/style/misc.hpp>  // For box
...
using namespace cycfi::elements;
...
auto subject = fixed_size({40, 40}, box(colors::gold));

auto column = vtile(
   halign(0.0, subject),               (1)
   halign(1.0, subject),               (2)
   halign(0.5, subject)                (3)
);

auto row = htile(
   valign(0.0, subject),               (4)
   valign(1.0, subject),               (5)
   valign(0.5, subject)                (6)
);
1 Align subject to the left.
2 Align subject to the right.
3 Align subject to the center.
4 Align subject to the top.
5 Align subject to the bottom.
6 Align subject to the middle.
