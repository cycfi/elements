Images

Overview

Three elements draw pictures:

  • image draws a picture at a scale of its size, fitted to the space it is given, or filling it.

  • sprite draws one frame of a strip of frames, chosen by index.

  • image_grid_menu and image_grid_cell show a picture cut into a grid of cells: the menu shows every cell and picks one; the cell shows the one picked.

The picture is an Artist image, loaded from a file or drawn in code, held through an image_ptr, a std::shared_ptr to it. A picture that cannot be used, a file that cannot be loaded or a null image_ptr, is reported to the error handler as image_load_failed, and then thrown.

Image

image(picture, scale) draws the picture at scale times its size, 1.0 by default. Its limits are that size, as both the minimum and the maximum.

image(picture, image::fit) and image(picture, image::fill) have no size of their own: their limits are from zero to full_extent, and the picture is drawn to the bounds the element is given. fit keeps the picture’s proportions, drawing it as large as fits and centring it; fill stretches it to the bounds on each axis.

set_image replaces the picture; a picture that cannot be used is reported and thrown, and the old one is kept. A scaled image takes the new picture’s size, so lay the view out again after a change of size.

Sprite

A sprite is an image of frames of one size, one under the other, of which it draws one. sprite(path, height, scale) takes the height of a frame as it is drawn, after scale; the sprite is the strip’s width times scale wide and height high. num_frames() is the strip’s height divided by the frame’s, and index(i) selects the frame to draw, ignoring an index past the last. A sprite is the subject of the sprite button and dial stylers, which set its index from their value; see Styles.

The same sprite, its index stepped through all its frames, beside a sprite of another strip: 101 frames of a knob drawn for a large, hi-fi amplifier look, shown larger. The look is the strip’s alone.

concepts::SpriteSubject is satisfied by a sprite and by any proxy whose subject, however deep, is a sprite.

Image Grid

An image grid is a swatch grid of a picture (see Swatches): the picture cut into columns by rows cells of equal size, numbered from the top left, row by row, from 0, one cell current.

  • image_grid_menu(picture, columns, rows, scale, highlighter) shows every cell, at scale times the picture’s size, to pick one from: a swatch_grid of an image.

  • image_grid_cell(picture, columns, rows, highlighter) shows the current cell alone, as large as fits in its bounds, its proportions kept: a swatch_cell of an image.

The highlighter is drawn over each cell shown. image_grid_menu without one uses swatch_highlighter, which outlines the current cell and tints the cell under the pointer. Picking, the value and its callback are a swatch grid’s.

Include

#include <elements.hpp>

Declaration

namespace cycfi::elements
{
   using artist::image_ptr;

   class image : public element
   {
   public:
      static constexpr auto fit = fit_enum{};
      static constexpr auto fill = fill_enum{};

                              image(fs::path const& path, float scale = 1);
                              image(image_ptr img, float scale = 1);
                              image(fs::path const& path, fit_enum);
                              image(image_ptr img, fit_enum);
                              image(fs::path const& path, fill_enum);
                              image(image_ptr img, fill_enum);

      virtual point           size() const;
      float                   scale() const;
      void                    set_image(image_ptr img);
      void                    set_image(fs::path const& path);
      image_ptr               get_image() const;
   };

   class basic_sprite : public image
   {
   public:
                              basic_sprite(fs::path const& path, float height, float scale = 1);

      std::size_t             num_frames() const;
      std::size_t             index() const;
      void                    index(std::size_t index_);
   };

   using sprite = basic_sprite;

   template <concepts::Element Highlighter, typename Image>
   auto
   image_grid_menu(
      Image&& img, int columns, int rows, float scale, Highlighter&& h);

   template <typename Image>
   auto
   image_grid_menu(Image&& img, int columns, int rows, float scale = 1);

   template <concepts::Element Highlighter, typename Image>
   auto
   image_grid_cell(Image&& img, int columns, int rows, Highlighter&& h);
}

Image is an image_ptr or an fs::path. The second image_grid_menu is in elements/element/style/image_grid.hpp.

Expressions

Notation

img

An image.

s

A sprite.

c, r

int: the number of columns and rows.

hl

An element, the highlighter.

pic

An fs::path or an image_ptr.

k

A float scale.

h

A float, a frame’s height as drawn.

i

An index.

Semantics

Expression Semantics

image(pic, k)

The picture at k times its size, 1.0 by default.

image(pic, image::fit)

The picture, as large as fits in the bounds, its proportions kept, centred.

image(pic, image::fill)

The picture stretched to the bounds.

img.size()

The size drawn, for a scaled image; {-1, -1} for a fitted or filled one.

img.set_image(pic)

Replace the picture.

sprite(path, h, k)

A sprite of the strip at path, its frames h high as drawn, at scale k.

s.num_frames()

The number of frames in the strip.

s.index(i)

Draw frame i; an index past the last is ignored.

image_grid_menu(pic, c, r, k, hl)

A swatch grid of pic at k times its size, in c by r cells.

image_grid_menu(pic, c, r [, k])

The same, with a swatch_highlighter.

image_grid_cell(pic, c, r, hl)

A swatch cell of pic, in c by r cells, showing the current one.

Example

A picture filling the view behind a knob sprite that shows a value from 0.0 to 1.0:

auto knob = share(sprite{"knob_sprites.png", 64, 0.5});

auto show = [knob, &view_](double v)
{
   knob->index(std::size_t(v * (knob->num_frames() - 1)));
   view_.refresh(*knob);
};

view_.content(
   align_center_middle(hold(knob)),
   image{"space.jpg", image::fill}
);
show(0.7);
