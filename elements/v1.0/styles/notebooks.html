Notebooks

Overview

A notebook shows one page at a time, with a row of tabs that switch between them. The pages are a deck (see Decks), and each tab is a button: a click on a tab brings up its page. Only one tab is on at a time, as with radio buttons, and the first is on when the notebook is made.

The tabs go above the pages, or down their left side:

Include

#include <elements/element/style/notebook.hpp>

Declaration

template <concepts::Element Button>
auto
tab(Button&& button);

auto
tab(
   std::string text
 , color active_color = get_theme().active_tab_color
);

template <typename Pages, typename... Tabs>
auto
vnotebook(view& view_, Pages&& pages, Tabs&&... tabs);

template <typename Pages, typename... Tabs>
auto
hnotebook(view& view_, Pages&& pages, Tabs&&... tabs);

template <typename Pages, typename Tab, typename... RestTabs>
void
link_tabs(view& view_, Pages pages, Tab tab, RestTabs... rest);

tab is declared in element/style/tab.hpp, which notebook.hpp includes.

Expressions

Notation

text

A std::string, the tab’s label.

c

A color.

b

An element, the look of a tab.

view_

The view the notebook is in.

d

A deck of the pages.

t1, …​ tN

Tabs, one per page, in the order of the pages.

dp

A std::shared_ptr to a deck of the pages.

tp1, …​ tpN

std::shared_ptr to tabs, one per page.

Factory

Each returns an element.

Expression Semantics

tab(text [, c])

Make a tab labelled text, drawn in c while on: the theme’s active_tab_color unless given.

tab(b)

Make a tab drawn by b.

vnotebook(view_, d, t1, …​ tN)

Make a notebook of the pages in d, with the tabs in a row above them.

hnotebook(view_, d, t1, …​ tN)

Make a notebook of the pages in d, with the tabs in a column at their left.

There must be as many tabs as pages. A deck made with deck(…​) has a fixed number of pages, so a different number of tabs does not compile. A deck_composite, whose pages can be added at run time, is checked when the notebook is made: a different number throws std::runtime_error.

A tab is a choice (see Buttons): when one tab is turned on, the others are turned off.

Operation

Expression Semantics Return Type

link_tabs(view_, dp, tp1, …​ tpN)

Link each tab to its page: selecting a tab selects its page. Turn the first tab on.

void

A notebook takes its pages and tabs by value. To keep them, to select a page from code or read which page is up, share them, link them with link_tabs, and lay them out yourself:

#include <elements/element/style/notebook.hpp>
#include <elements/element/style/misc.hpp>      // For box
...
using namespace cycfi::elements;
...
extern view view_;
...
auto pages = share(deck(box(colors::red), box(colors::green)));
auto red   = share(tab("Red"));
auto green = share(tab("Green"));

link_tabs(view_, pages, red, green);            (1)
auto notebook = vtile(
   align_left(htile(hold(red), hold(green))),   (2)
   hold(pages)
);
1 Link the tabs to the pages, and turn the first tab on.
2 The tabs in a row above the pages, as vnotebook lays them out.

link_tabs replaces each tab’s on_click.

Example

The notebook of the figure, from examples/notebook:

#include <elements/element/style/notebook.hpp>
#include <elements/element/label.hpp>           // For label
#include <elements/element/style/misc.hpp>      // For frame
...
using namespace cycfi::elements;
...
auto make_tabs(view& view_)
{
   auto make_page = [](auto text)
   {
      return layer(
         align_center_middle(label(text).font_size(100)),
         frame{}
      );
   };

   return vnotebook(                            (1)
      view_,
      deck(                                     (2)
         make_page("Dream"),
         make_page("Insanity"),
         make_page("Imagination")
      ),
      tab("Dream"),                             (3)
      tab("Insanity"),
      tab("Imagination")
   );
}
1 The tabs above the pages.
2 The pages.
3 One tab per page, in the order of the pages.
