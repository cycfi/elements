== Overview

A control is an element the user operates to set a value or trigger an
action. Each one splits behavior from looks: the control holds the state
and handles the mouse and keyboard, and a styler, any element, draws it
(see xref:styles.adoc[Styles]).

* xref:elements/buttons.adoc[Buttons]: momentary, toggle and latching
  buttons, and the radio buttons of a group.
* xref:elements/sliders.adoc[Sliders]: a thumb moved along a track,
  horizontal or vertical, and the range slider with two thumbs.
* xref:elements/dials.adoc[Dials]: a value set by turning, as a knob.
* xref:elements/thumbwheels.adoc[Thumbwheels]: a point, x and y, moved
  with the mouse.
* xref:elements/curve_editor.adoc[Curve Editor]: points dragged to shape
  a curve, as an envelope or an XY pad.
* xref:elements/swatches.adoc[Swatches]: samples to pick one from, as a
  palette of colors or a grid of thumbnails.
