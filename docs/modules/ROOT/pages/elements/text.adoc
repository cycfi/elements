= Text

include::../common.adoc[]

== Overview

Three elements show blocks of text, each built on the one before:

* `static_text_box` shows text, wrapped to the width it is given.
* `basic_text_box` adds editing: a caret, a selection, the keyboard, the
  mouse, the clipboard and undo.
* `basic_input_box` is a single line of input, with a placeholder and
  callbacks for each edit and for Enter.

image::elements/text.png[alt="A static text box of two wrapped lines, an editable text box with part of its text selected, and two input boxes, one showing its placeholder and one with text", width=440px, link={imagesdir}/elements/text.png]

For a single line that is not edited, use a
xref:elements/labels.adoc[label]. The framed input box most applications
use, `input_box`, is on the xref:styles/text_entry.adoc[Text Entry]
styles page.

=== Static Text Box

A static text box draws its text in a font and colour, by default the
theme's `text_box_font` and `text_box_font_color`, wrapped at the width
of its bounds. Line breaks in the text start new paragraphs. Its
{limits} are at least 200 wide and as high as the lines the text takes
at the width it was last laid out at, one line before the first layout;
there is no maximum. After a change that alters the number of lines,
lay the view out again.

The text is UTF-32 inside, and every position is an index of a code
point. It is read and replaced in UTF-32 or UTF-8, through
`text_reader_u32` and `text_writer_u32` (see
xref:support/text_utils.adoc[Text Utilities]), and as a
`receiver<std::u32string_view>` (see
xref:support/receivers.adoc[Receivers]). `insert`, `replace` and `erase`
change part of it.

=== Editable Text Box

A `basic_text_box` takes the focus, and with it the keyboard. Its
selection is a pair of positions, `select_start` and `select_end`; the
caret is at `select_end`. They are equal when nothing is selected, and
both `-1` when there is no caret at all, which is the case until the box
first takes the focus. A selection made backwards, with Shift-Left or a
drag to the left, has `select_start` after `select_end`.

The mouse:

* A click places the caret; Shift-click extends the selection to the
  click.
* A double click selects a word; a triple click selects a paragraph.
* A drag selects from the press to the pointer.
* Over the box, the cursor is an I-beam.

The keyboard, where Action is Command on macOS and Control elsewhere,
and Word is Option on macOS and Control elsewhere (the key codes and
modifiers are on the xref:view.adoc[View] page):

[cols="1,2"]
|===
| Key | Effect

| Left, Right
| Move the caret a character; with Word, a word. With Shift, extend the
  selection.

| Up, Down
| Move the caret a line, at the horizontal position it was last placed
  at by the mouse or by Left and Right.

| Home, End
| Move the caret to the start or the end of the text. With Shift, extend
  the selection.

| Backspace, Delete
| Delete the selection, or the character before or after the caret.

| Enter
| Start a new paragraph.

| Action-A
| Select all.

| Action-X, Action-C, Action-V
| Cut, copy and paste.

| Action-Z, Action-Shift-Z
| Undo and redo.
|===

Undo and redo go through the view's undo stack, so they reach every
text box in the view in the order the edits were made. Typing is undone
a run at a time, not a character at a time; a run ends at any other
edit, a caret move, a click, or when the box loses the focus.

`read_only()` keeps the selection and copying, and refuses every edit;
no caret is drawn. A disabled box, or a box drawn in a disabled
element, is drawn at the theme's `disabled_opacity`; a disabled box
refuses edits as well.

The caret blinks every half second while the box has the focus. After
each edit and caret movement, the box scrolls the enclosing
xref:elements/ports.adoc[port] so the caret stays in view; a text box
longer than its space belongs in a `vport` or a `scroller`.

=== Input Box

A `basic_input_box` is a text box of one line. Its height is one line in
its font, and its width is unbounded: it goes inside a horizontal port,
which shows part of it and scrolls with the caret. The stock
`input_box` provides the port and a frame.

While the box is empty, it shows its placeholder in its own font and the
theme's `inactive_font_color`. Four callbacks report what the user
does:

* `on_text(text)` after each change the user makes: typing, deleting,
  cutting, pasting, undo and redo.
* `on_enter(text)` on Enter. Returning `true` gives up the focus;
  `false` keeps it, for an entry that is not yet acceptable.
* `on_escape()` on Escape, which also gives up the focus.
* `on_end_focus(text)` when the focus is about to leave. Returning
  `false` keeps it.

An input box does not handle Tab, Up or Down, which go to the enclosing
elements; Action-Left and Action-Right act as Home and End. A paste
stops at the first line break. The text never grows past the theme's
`input_box_text_limit` characters: typing stops there, and a paste fills
only the room left.

When the box is neither focused nor under the pointer, its clip action
decides which part of a text too long for the port is shown:
`clip_right`, the default, shows the start and clips the end;
`clip_left` shows the end and clips the start; `clip_none` leaves the
port where it is.

== Declaration

```c++
namespace cycfi::elements
{
   class static_text_box
    : public element
    , public text_reader_u32
    , public text_writer_u32
    , public receiver<std::u32string_view>
   {
   public:
                              static_text_box(
                                 std::string_view text
                               , font_descr font_  = get_theme().text_box_font
                               , color color_      = get_theme().text_box_font_color
                              );

      std::u32string_view     get_text() const override;
      void                    set_text(std::u32string_view text) override;
      void                    set_text(std::string_view text);
      std::string             get_utf8() const;
      void                    set_utf8(std::string_view text);

      std::size_t             insert(std::size_t pos, std::string_view text);
      std::size_t             replace(std::size_t pos, std::size_t len, std::string_view text);
      void                    erase(std::size_t pos, std::size_t len);

      point                   current_size() const;
      void                    set_color(color c);
      color                   get_color() const;
      void                    set_font(font_descr f);
      font const&             get_font() const;
   };

   class basic_text_box : public static_text_box
   {
   public:
                              basic_text_box(
                                 std::string_view text
                               , font_descr font_ = get_theme().text_box_font
                              );

      int                     select_start() const;
      void                    select_start(int pos);
      int                     select_end() const;
      void                    select_end(int pos);
      void                    select_all();
      void                    select_none();
      void                    home(bool shift = false);
      void                    end(bool shift = false);

      bool                    is_focus() const;
      basic_text_box&&        read_only();
      void                    read_only(bool read_only_);
      bool                    editable() const;
   };

   class basic_input_box : public basic_text_box
   {
   public:
      using text_function = std::function<void(string_view text)>;
      using enter_function = std::function<bool(string_view text)>;
      using escape_function = std::function<void()>;

      enum clip_action { clip_none, clip_left, clip_right };

                              basic_input_box(
                                 std::string placeholder
                               , font_descr font_ = get_theme().text_box_font
                               , clip_action clip_action_ = clip_right
                              );

      text_function           on_text;
      enter_function          on_enter;
      escape_function         on_escape;
      enter_function          on_end_focus;
   };
}
```

== Expressions

=== Notation

`st`:: A `static_text_box`, or a class derived from it.
`tb`:: A `basic_text_box`, or a class derived from it.
`in`:: A `basic_input_box`.
`s`:: A `std::string_view` of UTF-8, or a `std::u32string_view`.
`f`:: A `font_descr`.
`c`:: A `color`.
`pos`, `len`:: `std::size_t` positions and lengths, in code points.
`i`:: An `int` position, or `-1`.

=== Semantics

[cols="1,2"]
|===
| Expression | Semantics

| `static_text_box(s, f, c)`
| A static text box of `s` in font `f` and colour `c`, by default the
  theme's.

| `st.get_text()`, `st.get_utf8()`
| The text, in UTF-32 or UTF-8.

| `st.set_text(s)`, `st.set_utf8(s)`
| Replace the text.

| `st.insert(pos, s)`
| Insert `s` before `pos`. Returns the number of code points inserted.

| `st.replace(pos, len, s)`
| Replace `len` code points from `pos` with `s`. Returns the number of
  code points inserted.

| `st.erase(pos, len)`
| Erase `len` code points from `pos`.

| `st.current_size()`
| The size the text took at the last layout.

| `st.set_color(c)`, `st.set_font(f)`
| Change the colour or the font.

| `basic_text_box(s, f)`
| An editable text box of `s` in font `f`.

| `tb.select_start(i)`, `tb.select_end(i)`
| Set either end of the selection; a position past the text is ignored.

| `tb.select_all()`, `tb.select_none()`
| Select the whole text, or remove the selection and the caret.

| `tb.home(shift)`, `tb.end(shift)`
| Move the caret to the start or the end of the text; with `shift`,
  extend the selection.

| `tb.read_only()`
| Make the box read only, as a modifier on construction:
  `basic_text_box("...").read_only()`.

| `tb.read_only(b)`
| Make the box read only, or editable again.

| `tb.editable()`
| Whether the box takes edits: neither read only nor disabled.

| `basic_input_box(p, f, a)`
| An input box with placeholder `p`, font `f` and clip action `a`.

| `in.on_text = fn`
| `fn(text)` is called after each change the user makes, undo and redo
  included.

| `in.on_enter = fn`
| `fn(text)` is called on Enter; it returns whether to give up the
  focus.

| `in.on_escape = fn`
| `fn()` is called on Escape.

| `in.on_end_focus = fn`
| `fn(text)` is called before the focus leaves; it returns whether to let
  it go.
|===

== Example

Notes in a scrolling box, and a name that must be entered before the
focus moves on:

```c++
auto notes = share(basic_text_box("Notes: the take at 2:14 is the keeper."));
auto notes_pane = scroller(margin({5, 5, 5, 5}, hold(notes)), no_hscroll);

auto [name_box, name] = input_box("Your name");
name->on_enter =
   [](std::string_view text)
   {
      if (text.empty())
         return false;     // keep the focus until a name is entered
      greet(text);
      return true;
   };
```
